Atalhos da Bíblia no Holyrics – Guia Completo

O Holyrics é um dos softwares mais utilizados em igrejas para projeção de letras, mensagens e versículos. Para quem opera durante o culto, saber usar os atalhos da Bíblia no Holyrics pode agilizar MUITO o trabalho e evitar erros ou atrasos. Aqui você encontra um guia completo com todos os atalhos oficiais do programa.

📌 Abrir e Exibir a Bíblia

  • F5 ou ENTER — Exibir o versículo selecionado
  • F12 — Abrir configurações da Bíblia
  • Ctrl + F — Buscar na Bíblia
  • Shift + Ctrl + F — Buscar apenas no livro atual

📖 Navegação e Comparação

  • Ctrl + O — Comparar versões da Bíblia
  • Shift + F5 — Leitura responsiva
  • F7 ou Ctrl + H — Voltar para a janela principal

🔢 Versículos por Slide

  • Ctrl + 1 — Exibir 1 versículo
  • Ctrl + 2 — Exibir 2 versículos
  • Ctrl + 3 — Exibir 3 versículos
  • Ctrl + 4 — Exibir vários versículos (modo automático)
  • Shift + Ctrl + Down — Aumentar quantidade
  • Shift + Ctrl + Up — Diminuir quantidade

👁️ Modo de Exibição

  • Ctrl + R — Mostrar apenas a referência
  • Ativar/desativar segunda versão — (não configurado)
  • Ativar/desativar terceira versão — (não configurado)

📚 Seleção Rápida de Versão

  • B — Abrir aba 1 das versões
  • Ctrl + B — Abrir aba 2 das versões
  • Shift + B — Abrir aba 3 das versões
  • . — Primeiro atalho de versão
  • Ctrl + . — Segundo
  • Shift + . — Terceiro

🎥 Exibição Rápida

  • Ctrl + Enter — Mostrar apenas primeiro versículo
  • Shift + Enter — Mostrar todos os versículos da seleção

⭐ Favoritos e Playlists

  • Alt + Enter — Adicionar aos favoritos
  • Ctrl + Alt + Enter — Adicionar à barra de favoritos
  • Shift + Ctrl + Alt + Enter — Adicionar à barra com versão
  • Ctrl + L — Adicionar à playlist
  • Shift + Ctrl + B — Ativar/desativar favoritos

🔍 Outros

  • Ctrl + F5 — Abrir referência rápida

Dominar esses atalhos vai ajudar você a operar o Holyrics com muito mais rapidez, precisão e segurança durante qualquer culto ou evento. Recomendo memorizar os atalhos que você mais usa para facilitar ainda mais o dia a dia!
